# 官方來源紀錄：數位發展部「網路詐騙通報查詢網」與「111 政府專屬短碼簡訊」

- **官方標題**：數發部網路詐騙通報查詢網 ／ 數位發展部（111 政府專屬短碼簡訊）
- **發布機關**：數位發展部（MODA）及數位產業署
- **原始網址**：
  - 網路詐騙通報查詢網：https://fraudbuster.digiat.org.tw/（重導向至 https://fraudbuster.digiat.org.tw/accessibility/index）
  - 數位發展部官網：https://moda.gov.tw/
- **實際查閱日期**：2026-11-23（HTTP 200 驗證通過）
- **來源類型**：台灣官方網路詐騙通報查詢平台與政府簡訊防偽機制
- **涵蓋主題**：
  1. **網路詐騙通報查詢網**：提供民眾查詢與通報可疑釣魚網站、假投資廣告、詐騙 LINE ID 或社群貼文；經審查確認後依法通知 Meta、Google、LINE、TikTok 等平台下架。
  2. **111 政府專屬短碼簡訊**：政府機關統一發送短碼「111」，搭配防偽識別標記（如接收者手機號碼末 3 碼、機關具名），協助民眾辨別真假政府簡訊，防範釣魚簡訊（Smishing）。
  3. **釣魚簡訊防範**：切勿點擊不明短網址或在陌生網頁輸入身分證字號、信用卡號、網銀密碼或 OTP 驗證碼。
