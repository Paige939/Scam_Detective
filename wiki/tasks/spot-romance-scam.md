# 辨識網路交友愛情詐騙警訊 SOP

## 1. 任務目標

幫助使用者在網路交友或社群互動中，及早察覺「長期情感養成（Grooming）」與階梯式詐財警訊，避免因情感投入與心理壓力而匯款、拍攝私密影像或落入二次詐騙。

> ⚠️ **證據界線**：本清單屬 📚 **教學延伸建議**，係依據 [[wiki/papers/Whitty2013|Whitty (2013)]] 對 20 名英國／美國受訪者的質性訪談框架轉譯而成。該研究未實驗測試本清單的防詐成效，且七階段並非每位受害者皆會完整經歷；請作為自我檢視與親友提醒工具。

---

## 2. 偵探檢驗清單 (Checklist)

> 📚 = 教學延伸建議（背景來源標註 PDF 頁碼）；🔗 = 待 165 官方補強

### 📚 Step 1：檢視「完美人設」與「永遠見不到面」
*(背景：[[wiki/papers/Whitty2013#F1｜七階段「詐騙者說服技術模型」（Scammers Persuasive Techniques Model）|Whitty 2013, PDF p.23–25]])*
- [ ] 對方背景是否高度契合理想（如海外專業人士、軍官、高資產鰥夫或亮眼模特兒照），卻總以海外工作、派駐等理由**長期無法面對面見面**？
- [ ] 對方是否透過早晚高頻訊息迅速表白，讓我把重心完全放在這段線上關係、減少與現實親友討論？

### 📚 Step 2：警惕「小額試探」與「突發危機」
*(背景：[[wiki/papers/Whitty2013#F1｜七階段「詐騙者說服技術模型」（Scammers Persuasive Techniques Model）|Whitty 2013, PDF p.26–29]])*
- [ ] 對方是否先要求寄送小禮物或小額金錢「試水溫」（Foot-in-the-Door）？
- [ ] 對方是否突然遭遇**緊急危機**（赴機場途中車禍、包裹卡海關、海外醫療費），催促立刻匯款、不給查證時間？
- [ ] 當我拒絕大筆金額後，對方是否立刻「退而求其次」改要較小金額（Door-in-the-Face）？
- [ ] 是否一再出現「**差一點就要見面／成功**，卻在最後一刻出意外」的劇本（Near-Win）？

### 📚 Step 3：不單憑對方寄來的「證明文件」
*(背景：[[wiki/papers/Whitty2013#F3｜精細推敲可能性模型（ELM）不足以解釋；作者改以認知失調（Cognitive Dissonance）詮釋|Whitty 2013, PDF p.20]])*
- [ ] 我了解對方寄來的登機證、工作證、政府公文或機構 Logo **皆可輕易偽造**，不能作為關係真實性的保證。
- [ ] 若我發現自己在幫對方的矛盾說法找藉口，我願意停下來請**現實中信任的親友**用旁觀者角度一起檢視。

### 📚 Step 4：守住影像與「二次詐騙」底線
*(背景：[[wiki/papers/Whitty2013#F1｜七階段「詐騙者說服技術模型」（Scammers Persuasive Techniques Model）|Whitty 2013, PDF p.30–31]])*
- [ ] 我絕不與未曾真實見面確認身分的網友進行裸露或私密視訊（防範錄影勒索）。
- [ ] 若已受騙，我絕不相信任何自稱「警方、律師、駭客」要求**先付手續費才能追回款項**的訊息（防範二次受害）。

### 🏛️ Step 5：警惕台灣高發「假交友結合投資」與官方查證（官方來源已驗證）
*(官方依據：[[wiki/sources/TW165-Dashboard|165 打詐儀錶板]]、[[wiki/sources/TW165-Portal|165 全民防騙網]]、[[wiki/sources/FSC-AntiFraud|金管會]])*

- [ ] 對方是否在建立感情後，順勢推薦「穩賺不賠、高報酬」的投資網站／App，初期讓小額出金、後期以「保證金／稅金」拒出金？（假交友結合投資詐騙）
- [ ] 投資前先至 **金管會官網（https://www.fsc.gov.tw/）** 確認是否為合法金融機構，遵守「三不三要」（不聽、不加、不用；要警覺、要查證、要報警）
- [ ] 撥打 **165 反詐騙諮詢專線** 或至 **165 全民防騙網（https://165.npa.gov.tw/）** 查詢詐騙 LINE ID 與涉詐網站

## 3. 應對處置 SOP

1. **暫停匯款與聯絡**：只要涉及未見面網友要求匯款、買點數、代收包裹、投資未核准平台或匯入私人帳戶，一律立即暫停。
2. **引入外部視角**：將對話紀錄與對方理由分享給信任的家人或朋友，打破封閉資訊環境。
3. **保留完整證據**：截圖對話（含對方暱稱、ID、頭像、時間）、轉帳明細、收款帳號／虛擬貨幣錢包地址、詐騙網址與 App 名稱。
4. 🏛️ **黃金止付與正式報案**：若已匯款，立即撥打 **165** 並聯繫轉出銀行啟動警示帳戶圈存，接著攜帶證據親赴全國任一派出所製作筆錄，取得 **「受（處）理案件證明單」**（[[wiki/sources/TW165-Portal|165 全民防騙網]]）。
